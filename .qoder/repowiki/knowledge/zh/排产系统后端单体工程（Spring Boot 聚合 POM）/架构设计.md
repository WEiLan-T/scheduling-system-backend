根 pom.xml 以 spring-boot-starter-parent 为父工程，集中声明 Web、JPA、PostgreSQL、Security+JWT、Lombok、POI-OOXML、BouncyCastle 等共享依赖，所有代码位于同一模块下，按目录约定划分边界：controller/dto/security/config 构成 Web 接入层；service 下的 AuthService/OrderService/DataEntryService/EstimationService 作为业务服务聚合层；service/scheduling 内的五个排产组件通过 Spring Bean 协作完成机台与产线按型号日产能智能匹配、人工调整后重算、询单反推资源以及多订单交货期紧→松贪心不回溯排产；domain + repository 提供领域模型与数据访问；static 存放 Vue SPA 静态资源。启动入口由 Spring Boot Maven Plugin 打包，运行即加载全部分层，各层之间通过 Spring IoC 注入交互，无显式进程间通信。
