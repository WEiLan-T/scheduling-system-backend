本模块为 Spring Boot 的 `@Service` 层，四个类各自封装一个业务域，依赖方向严格单向：service → repository/domain/dto/util，不反向依赖 controller 或 scheduling 内部实现细节。
- `AuthService`：基于 `SystemUserRepo` 和 Spring Security `PasswordEncoder` 完成用户名唯一性校验与密码单向哈希注册。
- `OrderService`：通过 `ProductionOrderRepo` 管理销售订单，内置 Apache POI 动态表头解析引擎，支持按列名模糊匹配导入、联合键去重、总长度自动推导及 Excel 导出。
- `DataEntryService`：协调织造(`WeavingDailyLog`)与共挤(`CoexDailyLog`)两条生产线的台账 CRUD，并通过私有 `updateVirtualWarehouse` 方法维护 `VirtualWarehouse` 虚拟库存；同时管理 `ProductProcess` 工艺路线，所有写操作均加 `@Transactional`。Excel 导入/导出能力已委托至 `WeavingImportService`、`CoexImportService`、`DataExportService`，旧入口通过 `@Deprecated` 方法保持兼容。
- `EstimationService`：作为排产 Facade，委托 `SchedulingEngine`、`ScheduleCommitter`、`InquiryCalculator`、`CapacityMatcher` 等子组件完成单/多订单排产预览、询单反算、最终排产提交与执行状态统计，并在 `getScheduleExecutionStatus` 中预加载日志避免 N+1 查询。
